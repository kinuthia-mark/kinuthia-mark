# Hi, I'm Mark Kinuthia

Full-stack developer from Kenya. I build web applications end to end, from the database schema to the UI, and I'm especially interested in AI that runs offline on ordinary hardware, where patient or business data never has to leave the machine.

Right now I'm working on an offline clinical consultation assistant: local speech recognition with Whisper, a quantized medical LLM, and an encrypted local database, all running on a desktop with no internet connection.

## How I like to build

- Automated tests and CI, so a change that breaks something fails before it is merged
- Secrets in environment variables, never in the repository
- READMEs that explain how the system works, with diagrams, not just how to install it
